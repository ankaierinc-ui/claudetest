# PII Encryption System

## Overview

This document describes the encryption system for protecting Personally Identifiable Information (PII) - specifically email addresses and phone numbers - in the Shopify Contact Scraper.

**Status**: Phase 2.2 Implementation
**Security Level**: HIGH Priority
**Encryption Method**: AES-256-GCM (Authenticated Encryption)
**Key Derivation**: PBKDF2 (100,000 iterations)

## Architecture

### Components

#### PIIEncryption Class (`utils/encryption.js`)

The main encryption utility providing AES-256-CBC encryption with support for:

- **Individual Field Encryption**: Encrypt email or phone fields
- **Contact Object Encryption**: Encrypt entire contact records preserving structure
- **Batch Operations**: Encrypt/decrypt multiple contacts efficiently
- **Hashing & Verification**: Create searchable hashes without decryption
- **Masking**: Display safe representations of sensitive data

### Encryption Flow

```
Input: plaintext email/phone
  ↓
Generate random IV (12 bytes, 96-bit for GCM)
  ↓
Encrypt with AES-256-GCM using derived key
  ↓
Generate authentication tag (built-in to GCM, 16 bytes)
  ↓
Combine: IV || ciphertext || authTag
  ↓
Encode as Base64
  ↓
Output: encrypted string (safe for storage)
```

### Decryption Flow

```
Input: Base64 encrypted string
  ↓
Decode from Base64
  ↓
Extract: IV (first 12 bytes) || authTag (last 16 bytes) || ciphertext (middle)
  ↓
Verify authentication tag with AES-256-GCM
  ↓
Decrypt with AES-256-GCM using derived key
  ↓
Output: plaintext email/phone
```

## Security Properties

### Encryption Strength

| Property | Value | Notes |
|----------|-------|-------|
| **Algorithm** | AES-256-GCM | NIST approved, Authenticated Encryption |
| **Key Size** | 256 bits | 32 bytes, cryptographically secure |
| **IV Size** | 96 bits | 12 bytes (optimal for GCM), random per encryption |
| **Auth Tag Size** | 128 bits | 16 bytes, generated by GCM |
| **Mode** | GCM | Galois/Counter Mode with authenticated encryption |
| **Key Derivation** | PBKDF2 | 100,000 iterations with SHA-256 |
| **Authentication** | Built-in to GCM | Integrity & authenticity verification |

### Attack Prevention

#### Replay Attacks
- **Random IV**: Each encryption generates new random IV
- **HMAC Tag**: Prevents tampering or replacement

#### Dictionary Attacks
- **Random IV**: Same plaintext produces different ciphertext
- **Key Derivation**: PBKDF2 with 100,000 iterations (computationally expensive)

#### Brute Force
- **Key Strength**: 2^256 possible keys (practically infeasible)
- **Iterations**: 100,000 iterations increase time cost

#### Known Plaintext
- **CBC Mode**: Ciphertext block depends on all previous blocks
- **Random IV**: Each encryption is unique

### Limitations

1. **Not Searchable**: Encrypted email cannot be directly queried in database
   - **Solution**: Generate hash alongside encryption for deduplication

2. **Not Deterministic**: Cannot identify same plaintext from different ciphertexts
   - **Solution**: Use hash field for lookups, encrypted for storage

3. **Requires Key Management**: Key must be stored securely
   - **Solution**: Environment variables, secret manager, key rotation

## Setup & Configuration

### 1. Generate Encryption Key and Salt

Generate a secure key and salt (do this ONCE):

```bash
node -e "const PE = require('./utils/encryption'); console.log(JSON.stringify(PE.generateKeyAndSalt(), null, 2))"
```

Output example:
```json
{
  "key": "d3f8e9c2a1b4f7e5d0c3a8b1f9e2d7c0a5b8f1e4d9c2f7a0b3e8c1d6f9a2c5",
  "salt": "c2f5a8e1b4d7c0f3e6a9b2d5f8c1a4e7"
}
```

### 2. Add to `.env` File

Update your `.env` file with the generated values:

```env
# PII Encryption Configuration
PII_ENCRYPTION_KEY=d3f8e9c2a1b4f7e5d0c3a8b1f9e2d7c0a5b8f1e4d9c2f7a0b3e8c1d6f9a2c5
PII_ENCRYPTION_SALT=c2f5a8e1b4d7c0f3e6a9b2d5f8c1a4e7

# Optional: Encryption toggle
PII_ENCRYPTION_ENABLED=true
```

### 3. Initialize in Node.js

```javascript
const PIIEncryption = require('./utils/encryption');

// Initialize with environment variables
const encryption = new PIIEncryption(
  process.env.PII_ENCRYPTION_KEY,
  process.env.PII_ENCRYPTION_SALT
);
```

### 4. Validate Configuration

```javascript
// Test encryption roundtrip
const testEmail = 'test@example.com';
const encrypted = encryption.encrypt(testEmail);
const decrypted = encryption.decrypt(encrypted);

if (decrypted === testEmail) {
  console.log('✓ Encryption configured correctly');
} else {
  throw new Error('Encryption configuration failed');
}
```

## Usage Examples

### Basic Email Encryption

```javascript
const PIIEncryption = require('./utils/encryption');

const encryption = new PIIEncryption(
  process.env.PII_ENCRYPTION_KEY,
  process.env.PII_ENCRYPTION_SALT
);

// Encrypt single email
const email = 'user@example.com';
const encrypted = encryption.encrypt(email);
console.log('Encrypted:', encrypted); // Long base64 string

// Decrypt
const decrypted = encryption.decrypt(encrypted);
console.log('Decrypted:', decrypted); // 'user@example.com'
```

### Email Hashing & Verification

```javascript
// Create hash for deduplication (one-way)
const email = 'user@example.com';
const hash = encryption.hash(email);
console.log('Hash:', hash); // Hex string

// Later, verify if email matches hash
const isMatch = encryption.verifyHash('user@example.com', hash);
console.log('Match:', isMatch); // true

// Case-insensitive verification
const isMatchUppercase = encryption.verifyHash('USER@EXAMPLE.COM', hash);
console.log('Match (uppercase):', isMatchUppercase); // true
```

### Email Masking

```javascript
const email = 'john.doe@example.com';
const masked = encryption.maskEmail(email);
console.log(masked); // 'j****e@example.com'

// Display in logs safely
console.log(`Contacted: ${encryption.maskEmail(email)}`);
```

### Phone Masking

```javascript
const phone = '(555) 123-4567';
const masked = encryption.maskPhone(phone);
console.log(masked); // '(555) ***-4567'
```

### Contact Object Encryption

```javascript
const contact = {
  id: 1,
  name: 'John Doe',
  company: 'Acme Corp',
  url: 'https://example.com/contact',
  email: 'john@example.com',
  phone: '(555) 123-4567'
};

// Encrypt email and phone, preserve other fields
const encrypted = encryption.encryptContact(contact);
/*
{
  id: 1,
  name: 'John Doe',
  company: 'Acme Corp',
  url: 'https://example.com/contact',
  email_encrypted: 'FjK2m9...base64...',
  email_hash: 'a1b2c3...hex...',
  email_masked: 'j****n@example.com',
  phone_encrypted: 'Kj8x2m...base64...',
  phone_hash: 'd4e5f6...hex...',
  phone_masked: '(555) ***-4567'
}
*/

// Store encrypted_contact in database

// Later, decrypt
const decrypted = encryption.decryptContact(encrypted);
/*
{
  id: 1,
  name: 'John Doe',
  company: 'Acme Corp',
  url: 'https://example.com/contact',
  email: 'john@example.com',
  phone: '(555) 123-4567'
}
*/
```

### Batch Encryption

```javascript
const contacts = [
  { name: 'John', email: 'john@example.com', phone: '(555) 111-1111' },
  { name: 'Jane', email: 'jane@example.com', phone: '(555) 222-2222' },
  { name: 'Bob', email: 'bob@example.com', phone: '(555) 333-3333' }
];

// Encrypt all at once
const encrypted = encryption.encryptBatch(contacts);

// Store encrypted contacts in database
// ...

// Later, decrypt all
const decrypted = encryption.decryptBatch(encrypted);
```

## Key Management

### Secure Key Storage

**DO NOT**:
- Commit keys to git repository
- Hardcode keys in source code
- Share keys via email or chat
- Log unencrypted keys

**DO**:
- Store in `.env` file (git-ignored)
- Use environment variable manager (AWS Secrets, HashiCorp Vault)
- Rotate keys periodically
- Backup keys in secure location

### Key Rotation

When rotating keys:

1. **Generate new key and salt**:
   ```bash
   node -e "const PE = require('./utils/encryption'); console.log(JSON.stringify(PE.generateKeyAndSalt(), null, 2))"
   ```

2. **Create new encryption instance with old key**:
   ```javascript
   const oldEncryption = new PIIEncryption(
     process.env.PII_ENCRYPTION_KEY_OLD,
     process.env.PII_ENCRYPTION_SALT_OLD
   );
   ```

3. **Create new encryption instance**:
   ```javascript
   const newEncryption = new PIIEncryption(
     process.env.PII_ENCRYPTION_KEY_NEW,
     process.env.PII_ENCRYPTION_SALT_NEW
   );
   ```

4. **Re-encrypt all data**:
   ```javascript
   // Read from Google Sheets
   const allContacts = await getContactsFromSheets();

   // Decrypt with old key
   const decrypted = oldEncryption.decryptBatch(allContacts);

   // Encrypt with new key
   const reencrypted = newEncryption.encryptBatch(decrypted);

   // Update Google Sheets
   await updateContactsInSheets(reencrypted);
   ```

5. **Update environment variables**:
   ```env
   PII_ENCRYPTION_KEY=<new-key>
   PII_ENCRYPTION_SALT=<new-salt>
   ```

## Performance Considerations

### Encryption Performance

- **Single email encryption**: ~1-5ms
- **Single contact encryption**: ~2-10ms (2 fields)
- **Batch encryption (1000 contacts)**: ~100-500ms
- **PBKDF2 key derivation**: ~50-100ms (per instance)

### Optimization Strategies

1. **Reuse encryption instance**:
   ```javascript
   // GOOD: Create once
   const encryption = new PIIEncryption(key, salt);

   const email1Encrypted = encryption.encrypt(email1);
   const email2Encrypted = encryption.encrypt(email2);
   ```

   ```javascript
   // BAD: Create for each encryption
   const email1Encrypted = new PIIEncryption(key, salt).encrypt(email1);
   const email2Encrypted = new PIIEncryption(key, salt).encrypt(email2);
   ```

2. **Batch operations** for multiple items:
   ```javascript
   // Faster
   const encrypted = encryption.encryptBatch(contacts);
   ```

3. **Use hashing for searches** instead of decryption:
   ```javascript
   // Search by email hash (no decryption needed)
   const targetHash = encryption.hash('user@example.com');
   const found = contacts.find(c => c.email_hash === targetHash);
   ```

## Recovery & Decryption

### Accessing Encrypted Data

When you need to work with decrypted data:

1. **Decrypt single contact**:
   ```javascript
   const encrypted = await getContactFromSheets(contactId);
   const decrypted = encryption.decryptContact(encrypted);
   ```

2. **Decrypt batch for export**:
   ```javascript
   const encrypted = await getAllContactsFromSheets();
   const decrypted = encryption.decryptBatch(encrypted);

   // Export to CSV
   const csv = convertToCSV(decrypted);
   ```

3. **Deduplication using hashes**:
   ```javascript
   const newContact = {
     email: 'user@example.com',
     phone: '(555) 123-4567'
   };

   const emailHash = encryption.hash(newContact.email);
   const phoneHash = encryption.hash(newContact.phone);

   // Check if already exists
   const exists = contacts.some(c =>
     c.email_hash === emailHash || c.phone_hash === phoneHash
   );
   ```

### Data Loss Scenarios

**Lost Encryption Key**:
- **Impact**: Data CANNOT be recovered
- **Prevention**: Backup key in secure location
- **Recovery**: No recovery possible

**Corrupted Encrypted Data**:
- **Impact**: Individual contact cannot be recovered
- **Prevention**: Store hashes for verification
- **Recovery**: Restore from backups

**Wrong Key Used**:
- **Impact**: Decryption will fail
- **Prevention**: Use environment variable management
- **Recovery**: Use correct key, decrypt again

## Troubleshooting

### Issue: Decryption Fails

**Error**: `Decryption failed: Unsupported state or unable to authenticate data`

**Causes**:
1. Wrong encryption key
2. Corrupted encrypted data
3. Different salt used

**Solution**:
```javascript
// Verify key configuration
console.log('Key length:', process.env.PII_ENCRYPTION_KEY.length); // Should be 64+
console.log('Salt length:', process.env.PII_ENCRYPTION_SALT.length); // Should be 32+

// Test with known value
const test = encryption.encrypt('test');
const decrypted = encryption.decrypt(test);
console.log('Test passed:', decrypted === 'test');
```

### Issue: Performance Degradation

**Symptoms**: Slow encryption/decryption

**Causes**:
1. Creating new encryption instance for each operation
2. Processing very large strings
3. Insufficient system resources

**Solution**:
```javascript
// Reuse instance
const encryption = new PIIEncryption(key, salt);

// Process in batches
const batch = contacts.slice(0, 100);
const encrypted = encryption.encryptBatch(batch);
```

### Issue: Hash Mismatch

**Error**: Hash verification fails

**Causes**:
1. Email case sensitivity (should be case-insensitive)
2. Whitespace differences
3. Different encryption instance

**Solution**:
```javascript
// Always normalize before hashing
const email = userInput.trim().toLowerCase();
const hash = encryption.hash(email);

// Verify
const isMatch = encryption.verifyHash(email, hash); // Should be true
```

## Examples: Integration Workflow

### Full Workflow Integration

```javascript
// In n8n Node 8 (Extract Contact Info)

const PIIEncryption = require('./utils/encryption');

// Initialize encryption (once per workflow run)
if (!global.encryption) {
  global.encryption = new PIIEncryption(
    process.env.PII_ENCRYPTION_KEY,
    process.env.PII_ENCRYPTION_SALT
  );
}

const encryption = global.encryption;

// Extract contact information
const contact = {
  store_url: item.store_url,
  contact_url: item.contact_url,
  name: extractedName,
  email: extractedEmail,
  phone: extractedPhone,
  form_fields: formFieldsFound,
  confidence_score: calculateConfidence(extractedEmail, extractedPhone)
};

// Validate
if (!contact.email && !contact.phone) {
  return {
    ...contact,
    extraction_status: 'NO_CONTACT_INFO'
  };
}

// Encrypt PII
const encrypted = encryption.encryptContact(contact);

// Add extraction metadata
encrypted.extracted_at = new Date().toISOString();
encrypted.workflow_id = context.workflow.id;
encrypted.extraction_source = 'shopify_contact_scraper_v3';

// Return for storage
return encrypted;
```

# Data Analysis Task

This folder is dedicated to data analysis projects.

## Structure

- Place your data files here for analysis
- Analysis results and reports will be generated in this directory

## Resources

- `claude-code-data-science-team/` - Reference project for multi-agent data science workflows (cloned from https://github.com/HungHsunHan/claude-code-data-science-team)

## Installed Skills

175 global skills are available for data analysis, including:
- Data processing: pandas, polars, dask, vaex
- Statistical analysis: statsmodels, scipy, pymc-bayesian-modeling
- Machine learning: scikit-learn, transformers, pytorch-lightning
- Visualization: matplotlib, seaborn, plotly
- Scientific computing: numpy, sympy, biopython
